# Knowledge Base design QA history

The original target is `Knowledge Base.dc.html` in the preserved [Learning Dashboard archive](../Learning%20Dashboard/Learning%20Dashboard%20technical%20specs.zip), together with the design conversation's Knowledge Base screenshot. The 2026-11-26 published MagicPath preview was outdated: it showed five flat sample items and lacked the intended taxonomy. A hosted submission of the corrected source was blocked by the MagicPath usage limit.

The [local preview](../preview/README.md) now renders the corrected source directly. Its [desktop Knowledge Base capture](../screenshots/11-knowledge-base-desktop.png) shows the grammar tree, domain tabs, 24 grammar items, search, learner-status filters, bookmarks and rule actions. The [390px capture](../screenshots/20-knowledge-base-telegram.png) confirms the same source renders at Telegram width. Both were captured from the local source; no hosted publication is needed.

Visual inspection confirms the main taxonomy and list composition from the archived reference. The original conversation attachment is not stored in the repository, so a pixel-perfect comparison to that attachment cannot be reproduced from a clean checkout. Prototype learner statuses and content are sample data, not Rule Book API output.
