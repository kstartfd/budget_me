Политика конфиденциальности Subtitle Translator

Subtitle Translator помогает переводить и разбирать выбранный текст и субтитры. Расширение работает в двух режимах, и в каждом данные идут по-своему. Режим выбирает пользователь в настройках расширения.

Какие данные обрабатываются

  • Расширение читает субтитры на поддерживаемых видеосайтах и выделенный пользователем текст на открытой странице. Для разбора может использовать соседние реплики, ближайший текст страницы и её заголовок как контекст.
  • Настройки, введённые API-ключи, токены, выбранные фразы, карточки словаря и временный кэш субтитров хранятся в хранилище Chrome на устройстве пользователя. Эти данные не синхронизируются между устройствами.
  • Если пользователь входит в аккаунт Learning, расширение обрабатывает email и пароль этого аккаунта. Они отправляются один раз на сервер Learning по HTTPS, чтобы получить токен сессии. Пароль расширение не сохраняет. Хранится только токен сессии (срок действия 30 дней), email для подписи в настройках и последний полученный список тем и описание агента: провайдер, модель, effort и последние четыре символа ключа. Сам ключ агента сервер Learning расширению не передаёт.

Режим 1. Свой ключ ИИ

При запросе перевода или разбора выбранный текст и относящийся к нему контекст отправляются напрямую выбранному пользователем поставщику ИИ с API-ключом пользователя. Поставщик выбирается в настройках: Anthropic, OpenAI, DeepSeek или любой OpenAI-совместимый адрес (по умолчанию API z.ai). Если пользователь включил автоперевод, туда же отправляются субтитры для перевода. Свой сервер расширение при этом не использует.

Режим 2. Агент из Learning

Если пользователь вошёл в Learning и выбрал агента из Learning, запрос перевода или разбора (выбранный текст, контекст и предыдущие реплики чата) отправляется на сервер Learning, указанный в настройках (по умолчанию learning.budgetme.xyz). Сервер вызывает поставщика ИИ, которого пользователь выбрал в Learning, ключом, сохранённым там, и возвращает ответ. Ключ хранится на сервере в зашифрованном виде и в расширение не передаётся. Приложение Learning не сохраняет текст этих запросов и не записывает его в журналы приложения; в журналах остаются служебные данные запроса (метод, путь, код ответа, время, IP-адрес). Поставщик ИИ обрабатывает запрос по собственной политике.

Сохранение фраз

При нажатии «Сохранить в словарь» карточка сначала сохраняется локально. Если пользователь вошёл в Learning или указал ссылку и токен, расширение отправляет подготовленную карточку (фраза, перевод, разбор, пример, источник) на сервер. После входа карточка отправляется на сервер Learning с токеном сессии в выбранную пользователем тему. Без входа — с указанным пользователем токеном на указанную им ссылку: это может быть Learning или любой другой сервис, который пользователь выбрал сам; расширение не передаёт карточки на адреса, которых пользователь не указывал. Для сервисов, кроме Learning, тема не передаётся. По умолчанию в поле ссылки указан learning.budgetme.xyz; без входа и без токена отправки нет. Что делает выбранный пользователем сервис с полученной карточкой, определяется его собственной политикой. Состав запроса показан по кнопке ? рядом со ссылкой для сохранения в настройках расширения.

Использование и управление данными

Данные используются только для функций перевода, разбора и сохранения фраз. Расширение не передаёт их для рекламы и не продаёт. Пользователь может в любой момент:

  • выйти из Learning кнопкой «Выйти» в настройках: токен сессии, email и список тем удаляются из браузера. Токен сессии не имеет состояния на сервере и перестаёт действовать по истечении 30 дней;
  • сменить или удалить API-ключи, токены и адреса серверов в настройках;
  • очистить кэш субтитров в настройках расширения и удалить все локальные данные через настройки Chrome или удаление расширения.

Карточки, уже сохранённые в аккаунте Learning, удаляются в самом Learning. Сроки хранения и обработка данных внешними поставщиками ИИ зависят от выбранных пользователем сервисов и их собственных политик.

Использование информации, полученной через API Google, соответствует правилам Chrome Web Store User Data Policy, включая требования Limited Use: данные используются только для описанных функций расширения, не продаются и не передаются рекламным платформам.

Вопросы о расширении и его обработке данных можно направить через страницу поддержки.
